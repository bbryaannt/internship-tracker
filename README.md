# Internship Tracker

A reusable Codex skill that extracts internship information from job postings and saves it to my Notion tracker.

See [.agents/skills/internship-tracker/README.md](.agents/skills/internship-tracker/README.md) for cloud commands, secure setup, tested capabilities and remaining device checks. Authorized schema mapping, extraction, duplicate checks, dry runs and verified-creation code are implemented. The approved first live write passed property, body and Bryant-relation verification. Normal additions are enabled; mobile workflow validation remains pending.

In a Codex cloud task for this repository, paste one or more job-posting links directly. The repository’s `AGENTS.md` routes them to the tracker automatically; `$internship-tracker` is optional. Add “check duplicates only” or “dry run” when you want no writes.
